## 环境与命令

原生微信小程序（JS/WXML/WXSS），无第三方 npm 依赖，无需 npm install，也无需运行 Web 开发服务器或「构建 npm」。
本次配置使用 Node.js 24.19.0，`.nvmrc` 已记录版本；装有 nvm 时可运行 `nvm use`。

- `npm run dev`：打开微信开发者工具。
- `npm run check`：只读检查 JSON、页面文件和 JavaScript 语法。
- `npm run update-dict` / `npm run convert-json`：原有词库维护脚本，会写文件；仅在确认数据来源和修改范围后运行。

原有 `npm test` 是占位命令，test/userTitleTest.js 是依赖微信运行环境的日志示例，不是完整自动化测试。
公共配置 project.config.json 指定基础库 3.8.7；仓库自带私有配置覆盖为 3.8.12。本次保留原值，首次打开由工具下载相应基础库。

## 网络数据与验证

词库不在本仓库内，实际来自 https://xyy1090091952.github.io/MeowBread_database/ 。图片还使用 free.picui.cn，部分配置包含 jsDelivr 模板占位值，后续替换资源时需单独核对。

## 后续开发

开发与 Git 交付遵循 [B++流程](B++流程.md)。默认基线为 `main`，任务分支为 `zoichi/任务简称`；「本地保存一下」只提交到本地，「按 B++ 继续下一步」才合并、推送并核对远端。本次环境配置没有自动提交或推送。
project.private.config.json 虽在 .gitignore 中，但历史已被 Git 跟踪，个人设置修改仍会出现在 git diff；提交前检查，避免误提交个人设置。
`output/`中的封面生成过程和已替换的`images/textbooks/try_n1.webp`保留在本地，不纳入Git；正式使用的封面是`try_n1_v6.webp`。上传配置同时排除生成目录、开发文档和脚本，避免将本地开发文件带入小程序包。
不要提交密钥、登录凭据或 .env。微信扫码登录与发布由账号持有人完成。
