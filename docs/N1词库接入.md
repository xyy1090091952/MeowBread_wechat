## 数据加载方式

独立词库仍为纯JSON。微信小程序不能直接require普通JSON，因此内置副本为 `database/try_n1/lesson1.js`，由同步命令生成，不手工维护两套内容。

`utils/lessonData.js` 只对准确匹配的N1第1课URL返回内置数据，其余词库仍请求网络。词汇计数、书籍选择和答题共用此入口。当前N1第1课优先使用内置版本，不依赖尚未发布的GitHub Pages资源；以后修改其JSON需同步并重新编译小程序，内置词库读取时绕过旧的词条及词汇量缓存，避免更新数据后仍显示旧词数或丢失新字段；其他词库保持原缓存逻辑。

```sh
npm run sync:n1
npm run check:n1 -- /Users/zoichi/Desktop/喵包词库/try_n1/lesson1.json
npm run check
```

词库不在默认相邻目录时，执行 `node scripts/sync-try-n1.cjs /实际位置/try_n1/lesson1.json`。
